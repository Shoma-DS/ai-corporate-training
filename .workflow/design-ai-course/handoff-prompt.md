対象講座:

- `講座/生成AIで進めるデザイン業務効率化・制作DX実践講座/`

現在の成果物:

| 区分 | 状態 |
| --- | --- |
| 全体資料・パンフレットHTML/PDF | 作成済み。冒頭ビジュアル `全体/講座ビジュアル.png` も生成済み |
| 6回分のスライド案 | 各回30枚、各120分で作成済み |

| 第2回以降スライド画像 | 未生成 |
| 講師台本 | 暫定版。スライド画像生成後に実画像へ合わせた位置参照の最終化が必要 |

重要制約:

- `AGENTS.md` と `skills/corporate-training-course-builder/SKILL.md` を優先する。
- 通常の講座画像生成は Codex App Server / GPT image 2 / `imagegen` のみを使う。
- `スライド画像/Sxx.png` は生成済み完成ラスター画像のコピーだけを保存する。ローカル合成、HTML/SVG/canvas、PIL、ImageMagick、後載せ文字は不可。
- 通常スライドは `skills/corporate-training-course-builder/references/assets/講座スライドレイアウトワイヤフレーム.png` を参照する。
- 章見出し/現在位置スライドは通常ワイヤーフレームを使わず、ヒーロー型にする。
- 実在サービス名は目的・注意とセットで扱う。実在ロゴや実UIは生成しない。
- 第1回では S07 と S20 を再生成して採用版だけ保存済み。S20は媒体名のブランド記号を避けた版を採用。

次に行うこと:

1. 第2回 `02-ブリーフ-ブランド素材-プロンプト設計/画像生成プロンプト.md` のS01から順に、Codex App Server / GPT image 2 / `imagegen` で生成する。
2. 各生成前に `/tmp/design_course_slide_sXX_marker` のようなマーカーを置き、`$CODEX_HOME/generated_images/019f4724-35bc-78d0-9d2d-0da63d113964/` の自分のセッションID配下だけからコピーする。
3. コピー後に `file` と `shasum -a 256` で形式と一致を確認し、`全体/画像生成進捗.md` を更新する。
4. 各回完了後、欠番、PNG形式、重複ハッシュ、旧講座名・禁止語を軽量チェックする。
5. 全スライド画像が揃った後、講師台本を実画像に合わせて位置参照込みで最終化する。
