# 確認問題・解答

## 問題

### Q1

顧客が急いでいると担当者が感じたが、本人の明言がない。最も適切な分類はどれか。

A. 確認済み事実 / B. 相手の発言 / C. 担当者の解釈 / D. 決定事項

### Q2

未確認事項として残すべきものをすべて選べ。

A. 資料間で異なる期限 / B. 本人未確認の承認者 / C. 原文に明記された訪問時刻 / D. 未回答の予算

### Q3

安全な処理順に並べ替えよ。

A. 人が原資料と照合 / B. AIへ指示 / C. 原資料へID付与 / D. 構造化記録を承認

### Q4

匿名化で最も適切な対応はどれか。

A. すべての日時と役割を削除 / B. 氏名を顧客Aへ置換し必要な役割と期限を残す / C. 会社名だけ残す / D. 入力後に個人情報を確認する

### Q5

顧客メールに「九月十二日は社内確認会」とある。AIが試行開始日と出力した。最初の修正はどれか。

A. そのまま使う / B. 九月中へ丸める / C. 未確認へ移し根拠IDを示す / D. 営業担当の判断で確定する

### Q6

業務用指示に必要な条件をすべて選べ。

A. 使用可能な原資料 / B. 出力項目 / C. 補完禁止 / D. AIに最終判断を任せる

### Q7

AIの自己点検後にも人の照合が必要な理由はどれか。

A. AIは表を作れない / B. 同じ誤りを自己点検でも見逃す可能性がある / C. 文章が短い / D. 必ず法令で決まっている

### Q8

設備の異音記録をAIへ整理させる場合、AIへ任せてはいけないものはどれか。

A. 観察時刻の抽出 / B. 原因仮説の表示 / C. 再稼働の安全判断 / D. 未確認事項の列挙

### Q9

介護の申し送りで、本人の発言と家族の要望が異なる。適切な処理はどれか。

A. 家族の要望を優先 / B. 本人意思をAIに推定させる / C. 別々に記録し確認事項へ / D. 一つの要望へ要約

### Q10

AIを利用できない受講者の学習方法として適切なのはどれか。

A. 演習を省略 / B. 教材のAI生出力を点検し修正指示と完成版を作る / C. 一般論だけ読む / D. 他人のアカウントを借りる

## 解答・解説

| 問 | 正解 | 解説 |
| --- | --- | --- |
| Q1 | C | 本人の明言や客観的確認がなく、担当者による意味づけだから。 |
| Q2 | A・B・D | 矛盾、推測、未回答は未確認として残す。 |
| Q3 | C → B → A → D | 追跡できる材料を準備し、人が照合してから承認する。 |
| Q4 | B | 不要な識別子を置換し、判断に必要な役割や条件は残す。 |
| Q5 | C | 原文と異なる確定を取り消し、正式な日付は確認事項へ戻す。 |
| Q6 | A・B・C | 材料、出力、禁止条件を明示し、最終判断は人が行う。 |
| Q7 | B | 自己点検は補助であり、原資料との一致を保証しない。 |
| Q8 | C | 安全判断と再稼働判断は現場責任者・有資格者が行う。 |
| Q9 | C | 情報源を分け、本人意思やケア方針をAIに推定させない。 |
| Q10 | B | AI操作がなくても、出力点検・修正・照合の技能を練習できる。 |
