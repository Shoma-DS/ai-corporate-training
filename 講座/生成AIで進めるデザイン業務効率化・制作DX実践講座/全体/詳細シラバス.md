# 詳細シラバス

対象講座: 生成AIで進めるデザイン業務効率化・制作DX実践講座

## 第1回: デザイン業務棚卸しとAI活用設計

- 到達点: 制作依頼から納品までを分解し、AIで短縮する場所と人が確認する場所を決める
- 成果物: デザイン業務棚卸し表、As-Is/To-Be制作フロー、AI活用候補選定表
- テーマ固有演習: つばめ商店のSNS投稿・商品画像・バナー制作を題材に、週5本の制作依頼を棚卸しする

| 大項目 | 小項目 | 時間 |
| --- | --- | --- |
| 導入と全体像 | 成果物、演習データ、利用ツール、情報管理の前提 | 15分 |
| 業務設計と素材整理 | 制作工程、入力情報、素材台帳、AIに渡す情報/渡さない情報 | 20分 |
| AI制作・レビュー実践 | プロンプト、出力比較、レビュー表、採用判断 | 25分 |
| 量産・連携・運用設計 | テンプレート、媒体展開、CSV量産、承認状態、MCP候補 | 30分 |
| 権利・品質・承認管理 | 権利、ブランド、事実、可読性、承認ログ、Content Credentials | 15分 |
| 演習レビューと次回接続 | 講師記入例との自己レビュー、次回または提案書への受け渡し | 15分 |
