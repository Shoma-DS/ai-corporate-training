# 第6回 演習データ

このフォルダのCSVはすべて架空データです。実在の顧客名、社員名、メールアドレス、電話番号、価格、契約条件、未公開商品情報は含めていません。

## この回の成果物

制作DX提案書、90日展開ロードマップ、効果試算表、運用開始チェックリスト

## データの使い方

- ワークシートの入力例として使います。
- Canva、Adobe Express、Figma、ChatGPT等の実サービスへ投入する場合は、導入時の利用規約、商用利用条件、管理者設定、AI学習設定、素材権利を確認してください。
- 講座内では、実在ロゴや実在UIの再現を画像生成AIへ依頼しません。
